# Pokémon App

A aplicação consiste numa Pokédex simples desenvolvida em React, que permite consultar informações sobre diferentes Pokémon através da PokéAPI. O projeto teve como principal objetivo consolidar os conhecimentos adquiridos na unidade curricular de React, recorrendo ao consumo de uma API externa e à criação de uma interface dinâmica.

## Funcionalidades

- Listagem de Pokémon através da PokéAPI - 20 por página.
- Pesquisa de Pokémon por nome.
- Paginação dos resultados.
- Visualização do número, imagem, nome, tipo, região e descrição de cada Pokémon.

## Tecnologias Utilizadas

- React
- Vite
- JavaScript (ES6+)
- Axios
- CSS3
- PokéAPI

## Instalação

1. Clonar o repositório:

   ```bash
   git clone <url-do-repositorio>
   ```

2. Entrar na pasta do projeto:

   ```bash
   cd pokemon-app
   ```

3. Instalar as dependências:

   ```bash
   npm install
   ```

4. Executar a aplicação:

   ```bash
   npm run dev
   ```

## API Utilizada

Este projeto utiliza a **PokéAPI** para obter os dados dos Pokémon.

- https://pokeapi.co/
